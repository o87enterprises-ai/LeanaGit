🛠️ 3. How to Update Your React App

Here’s how to integrate these into your project.

Step 1: Download & Add Assets

Run these commands in your project root (~/leana-campaign) to download the images directly:

```bash
# Create the images directory
mkdir -p public/images

# Download the logo, headshot, share image, and favicon
curl -o public/images/logo.png https://leanaforoaklandschools.com/images/logo.png
curl -o public/images/headshot.JPG https://leanaforoaklandschools.com/images/headshot.JPG
curl -o public/images/share-image.jpg https://leanaforoaklandschools.com/images/share-image.jpg
curl -o public/images/favicon.png https://leanaforoaklandschools.com/images/favicon.png
```

Step 2: Update index.html

Link the Google Fonts and set the favicon in your index.html file:

```html
<head>
  <!-- Favicon -->
  <link rel="icon" href="/images/favicon.png" type="image/png" />

  <!-- Google Fonts -->
  <link rel="preconnect" href="https://fonts.googleapis.com" />
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
  <link href="https://fonts.googleapis.com/css2?family=Alata&family=Lora:ital,wght@0,400;0,700;1,400&family=Roboto:wght@400;500;700;900&display=swap" rel="stylesheet" />
</head>
```

Step 3: Update tailwind.config.js

Replace your current Tailwind config with these brand colors and font families:

```js
/** @type {import('tailwindcss').Config} */
export default {
  content: ["./index.html", "./src/**/*.{js,ts,jsx,tsx}"],
  theme: {
    extend: {
      fontFamily: {
        'alata': ['Alata', 'sans-serif'],
        'roboto': ['Roboto', 'sans-serif'],
        'lora': ['Lora', 'serif'],
      },
      colors: {
        'brand-primary': '#C14507',
        'brand-primary-dark': '#a33a05',
        'brand-secondary': '#2E353D',
        'brand-text': '#343a40',
        'brand-bg': '#eaedf0',
        // Keep your other custom colors if you like
      },
    },
  },
  plugins: [],
}
```

Step 4: Apply the Styles to Components

· Navbar: Set the background to bg-brand-primary and text to text-white.
· Buttons: Use bg-brand-primary and hover:bg-brand-primary-dark.
· Body: Set the background to bg-brand-bg and text to text-brand-text.
· Headings: Use the font-alata class for a clean, modern look.
